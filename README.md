# NorrNote21FE — Friends Edition

Бесплатное некоммерческое приложение NORRVIND для заметок, списков, напоминаний и вложений на **Windows и Android** с двусторонней синхронизацией через Google Drive.

**Версия: 0.7.0.** Windows x64 уже опубликована; Android release APK собран и подписан, проверен на тестовом устройстве вместе с Windows. Замену файлов GitHub Release на окончательные сборки необходимо подтвердить отдельно: наличие исходного релиза не означает, что опубликованы последние hotfix-бинарники.

## Скачать

[GitHub Releases](https://github.com/yhelagin-dentalla/NorrNote21FE/releases) — используйте Windows ZIP и подписанный Android APK из раздела Assets. До завершения замены бинарников проверяйте дату файлов и опубликованную контрольную сумму. Автоматические архивы GitHub `Source code` — не установщики.

## Возможности

- Офлайн-заметки, списки, напоминания и виджеты на обеих платформах.
- Изображения, PDF и другие вложения; экспорт заметок и файлов.
- Sync21 v2: синхронизация между Windows и Android через собственную папку Google Drive `NorrNote21FE`.
- Отдельный Android package `su.norrvind.norrnote.fe`; личная NorrNote21 — другой проект.
- Windows ZIP содержит self-contained .NET, отдельно устанавливать .NET не требуется.

## Установка

**Windows:** скачайте ZIP, распакуйте целиком в постоянную папку, запустите `NorrNote21FE.exe` (не из просмотра ZIP). Не извлекайте отдельный EXE из комплекта.

**Android:** скачайте *release* APK, перенесите на телефон с Android 10+, разрешите установку из выбранного источника по запросу системы и установите. Не используйте debug APK.

**Синхронизация:** подключите один и тот же Google-аккаунт в обоих приложениях; разрешите запрошенный доступ Google Drive; дождитесь завершения синхронизации. Не редактируйте облачные `database-personal.json` и `blobs/` вручную.

## Проверка исправления вложений

11 октября 2026 тестовая связка FE прошла семь сценариев: заметка Windows→Android; PDF Windows→Android и сохранность его в Windows; изображение Android→Windows; удаление PDF с передачей удаления; отсутствие самовосстановления после повторной синхронизации; сохранность вложений после перезапуска обеих платформ. Это функциональное тестирование не доказывает отсутствие всех конфликтов одновременных офлайн-изменений.
