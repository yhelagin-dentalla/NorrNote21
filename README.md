# NorrNote21

**NorrNote21** — заметки, списки, напоминания и вложения для Android и Windows с синхронизацией через личный Google Drive. Разработчик: команда NORRVIND.

> **Статус: подготовка публичного релиза.** Проверенная версия разработчика: **0.7.0f**. Общедоступные установочные файлы пока **не опубликованы**.

## Возможности
- Заметки и списки на телефоне и компьютере, работа офлайн.
- Виджеты Android и Windows; напоминания.
- Прикрепление изображений, PDF, DOCX и других файлов.
- Двусторонняя синхронизация Sync21 v2 через личный Google Drive.
- «Поделиться»: без вложений — текст; с вложениями — один ZIP с текстом и файлами (`NNote_DD.MM.YYYY_1.zip`, `_2.zip` и т. д.).

## Как установить Android (после выхода публичного релиза)
1. Откройте страницу **[Releases](../../releases)**.
2. Скачайте **release APK**, а не Source code ZIP.
3. Сверьте опубликованную на странице релиза контрольную сумму SHA-256.
4. Разрешите установку APK из выбранного браузера или файлового менеджера, если Android запросит разрешение.
5. Установите и откройте NorrNote21, создайте тестовую заметку, добавьте виджет.

**Пока устанавливать сторонним пользователям нечего.** Перед выпуском мы должны исключить конфликт Android `applicationId` с другим приложением NorrNote11.

## Как установить Windows (после выхода публичного релиза)
1. Откройте **[Releases](../../releases)** и скачайте Windows installer или ZIP.
2. Сверьте SHA-256 с данными релиза.
3. Для ZIP: распакуйте в постоянный каталог (например `C:\Apps\NorrNote21`).
4. Запустите `NorrNote21.exe`. Если релиз требует .NET Desktop Runtime, скачайте официальную версию Microsoft, указанную в описании выпуска.
5. Создайте тестовую заметку и проверьте виджет.

## Как подключить синхронизацию Google Drive (после проверки OAuth)
1. На Android и Windows откройте настройки подключения Google Drive в приложении.
2. Выполните вход в **один и тот же Google-аккаунт** на обоих устройствах и предоставьте запрашиваемые разрешения.
3. Дождитесь окончания синхронизации, затем создайте заметку на одном устройстве и проверьте появление на другом.
4. В личном Google Drive используется папка `NorrNote21`: `database-personal.json` и `blobs/`. Не редактируйте эти файлы вручную.

**Важно:** OAuth вход для сторонних пользователей пока не подтверждён; до проверки на новых аккаунтах массовую установку не объявляем.

## Конфиденциальность и ограничения
Заметки хранятся локально и синхронизируются в ваш Google Drive. End-to-end шифрование не подтверждено. Не загружайте личные заметки, ключи, токены или базы данных в публичный репозиторий.
