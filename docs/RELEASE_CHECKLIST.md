# Публичный релиз: обязательные проверки

- [ ] Зафиксировать единый исходный снимок **0.7.0f**, не цепочку патчей.
- [ ] Назначить NorrNote21 уникальный Android `applicationId`, отличный от NorrNote11, и продумать миграцию установленных данных.
- [ ] Создать отдельный release-ключ Android, хранить его вне GitHub; собрать и проверить подписанный APK, вычислить SHA-256.
- [ ] Проверить Google OAuth для стороннего пользователя на Android и Windows, consent screen, область доступа Drive.
- [ ] Опубликовать необходимые документы о приватности и OAuth.
- [ ] Подготовить installer или self-contained Windows ZIP, протестировать на чистой Windows без .NET SDK.
- [ ] Убедиться, что NorrNote11 и NorrNote21 можно установить параллельно на Android.
- [ ] Проверить первый запуск, создание БД, виджеты и напоминания на обоих устройствах.
- [ ] Проверить синхронизацию, удаление заметок, картинки, PDF/DOCX, экспорт ZIP и восстановление после офлайн-работы.
- [ ] Проверить отсутствие токенов, ключей, персональных данных и баз в опубликованных файлах.
- [ ] Создать **GitHub Release**: Android APK, Windows пакет, контрольные суммы, changelog, инструкция обновления/отката.

## Только для разработчика (не публичная установка)
Android: `cd C:\Projects\NorrNote21\Android; .\gradlew.bat :app:assembleDebug`.

Windows: `cd C:\Projects\NorrNote21\Windows; dotnet publish .\NorrNote21.Windows.csproj -c Release --self-contained false -o .\Builds\0.7.0f`.

Эти команды не создают готовый публичный дистрибутив.
