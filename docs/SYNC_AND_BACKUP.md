# NorrNote21FE — Sync21 v2 и резервное копирование

Рабочая синхронизация FE использует отдельную папку Google Drive `NorrNote21FE`, маркер `norrnote21-fe-root-v1` и scope `drive.file`. Личная `NorrNote21` не используется.

- `database-personal.json` содержит снимок заметок, метаданные вложений и данные удаления.
- `blobs/` хранит содержимое файлов, связанное с метаданными по SHA-256.
- Локальные базы позволяют работать офлайн.
- Android FE: `su.norrvind.norrnote.fe`; Windows FE: отдельная папка локальных данных.
- Папка резервных копий Android FE должна быть `NorrNote21FE-Backups` — проверяйте при новых сборках.

## Исправление 11.10.2026

Первоначально файл, добавленный на Windows, исчезал после обмена с Android. Было выявлено опасное замещение всей заметки облачной версией, включая список вложений, и преждевременное подтверждение синхронизации. После изменения `Windows/Services/DriveSync.cs` и Android `Sync21Manager.kt` проверены семь сценариев:

1. Новая заметка Windows → Android.
2. PDF Windows → Android и открытие.
3. PDF сохраняется на Windows после повторной синхронизации.
4. Изображение Android → Windows и открытие.
5. Удаление PDF на Windows видно на Android.
6. После повторной синхронизации PDF не восстанавливается.
7. После перезапуска обеих программ вложения сохранены.

Результат: 7/7 тестов прошли. Не проверены все виды одновременных конфликтующих офлайн-изменений; не используйте Sync21 как многопользовательский редактор.

## Резервирование и восстановление

Перед заменой приложения, сменой аккаунта, очисткой данных, переустановкой или ремонтом синхронизации сохраните локальные данные и копию облачной папки. Не редактируйте `database-personal.json` и `blobs/` вручную, не подменяйте свежий снимок старым без плана восстановления. Не публикуйте базы и токены.
