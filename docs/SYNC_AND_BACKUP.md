# Sync21 v2: синхронизация и резервные копии

NorrNote21 синхронизирует личные заметки Android и Windows через отдельную папку Google Drive `NorrNote21`.

- `database-personal.json`: актуальный снимок заметок, метаданные вложений и идентификаторы удалённых заметок.
- `blobs/blob-<SHA256>`: содержимое прикреплённых файлов.
- На устройствах остаются локальные базы для работы без сети.

Один Google-аккаунт должен использоваться на всех устройствах одного пользователя. Sync21 не предназначена для совместного редактирования несколькими независимыми пользователями; одновременные конфликтующие офлайн-правки требуют дополнительной проверки.

## Резервное копирование
Перед удалением приложения, сменой Google-аккаунта, изменением Android applicationId или восстановлением сделайте копию локальных данных и облачной папки `NorrNote21`. Не заменяйте новый облачный снимок старым без плана восстановления. Никогда не загружайте личные базы и резервные копии в публичный GitHub.

При первом подключении проверяйте создание, редактирование и удаление заметок, синхронизацию вложений и напоминаний на отдельном тестовом аккаунте.
