# Ограничения до публичного релиза (октябрь 2026)

1. **Android applicationId:** NorrNote21 и NorrNote11 используют `su.norrvind.norrnote`. Перед независимым публичным выпуском нужен уникальный ID и план миграции данных.
2. **Google OAuth:** вход с нового стороннего аккаунта не проверен на обеих платформах. Уточнить consent screen, публикацию и разрешения Drive.
3. **Дистрибутивы:** подписанный release APK и проверенный на чистой Windows установочный пакет ещё не подготовлены. Debug APK не публиковать.
4. **Единая версия:** 0.7.0f получена цепочкой патчей. Для воспроизводимого релиза зафиксировать цельный исходный код.
5. **Не подтверждены:** сквозное шифрование, надёжное разрешение одновременных конфликтующих правок и Windows code signing.
