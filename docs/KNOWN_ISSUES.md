# NorrNote21FE 0.7.0 — известные ограничения

- **Одновременные офлайн-конфликты:** все случаи одновременной правки одной заметки и удаления/добавления вложений не проверены. Возможно повторное появление удалённого вложения при специальных конфликтных сценариях.
- **Шифрование:** сквозное end-to-end шифрование не подтверждено; не следует считать Google Drive зашифрованным хранилищем с E2EE приложения.
- **Windows code signing:** самодостаточный EXE не обязательно подписан сертификатом издателя; предупреждение SmartScreen возможно.
- **Google OAuth:** вход проверен на отдельном аккаунте, однако для других пользователей возможны предупреждения о статусе верификации приложения Google.
- **Границы проверки:** 11.10.2026 пройдены 7/7 функциональных тестов Sync21 с вложениями на связке Android/Windows, но это не полный аудит или автоматизированный регрессионный набор.
- **Публикация:** новая локальная сборка сама по себе не заменяет старый GitHub Release asset; до обновления бинарников сверяйте SHA-256 и версии в разделе Assets.
- **Не устанавливать debug APK:** он может иметь package ID личной NorrNote21; распространять только подписанный release APK `su.norrvind.norrnote.fe`.

При потере вложения не выполняйте повторную синхронизацию и очистку облака без резервной копии. Поддержка: support@norrvind.app.
