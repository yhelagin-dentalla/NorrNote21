# Установка NorrNote21 — инструкция для начинающих

> **На 10.10.2026 готового публичного установочного релиза ещё нет.** Доступные разработчику архивы исходников и тестовая Android-сборка не подходят для сценария «скачал и всё работает». Эта инструкция отделяет будущую установку от действий разработчика.

## Что нужно пользователю

- Телефон с Android **10 или новее**.
- Компьютер с Windows 10/11.
- Доступ к интернету и **один личный Google-аккаунт** для обоих устройств, если нужна синхронизация.
- Свободное место для заметок и вложений.

## 1. Установка на Android — после выхода Release

1. Откройте страницу [Releases](https://github.com/yhelagin-dentalla/NorrNote21/releases).
2. Найдите последний выпуск с пометкой **Stable**.
3. В разделе **Assets** скачайте файл с расширением **.apk**. Не выбирайте «Source code (zip)».
4. Откройте скачанный APK на телефоне. При запросе Android разрешите установку из того приложения, в котором открыли APK.
5. Нажмите «Установить», затем «Открыть».
6. Проверьте создание тестовой заметки. Для виджета: удерживайте палец на пустом месте домашнего экрана → «Виджеты» → NorrNote21 → разместите виджет.

**Пока эти шаги выполнить нельзя:** публичный подписанный APK отсутствует. Присланный `app-debug.apk` — тестовая сборка. Она имеет тот же идентификатор приложения `su.norrvind.norrnote`, что и NorrNote11, поэтому способна конфликтовать с ней. Не устанавливайте её вместо NorrNote11.

## 2. Установка на Windows — после выхода Release

1. На компьютере откройте [Releases](https://github.com/yhelagin-dentalla/NorrNote21/releases).
2. В последнем стабильном выпуске скачайте файл Windows ZIP или установщик.
3. Если это ZIP: щёлкните по файлу правой кнопкой → «Извлечь всё» → выберите постоянную папку.
4. Откройте распакованную папку и запустите `NorrNote21.exe`. Не запускайте из окна просмотра ZIP.
5. При сообщении «Требуется .NET» установите **.NET 8 Desktop Runtime для Windows** с официального сайта Microsoft, если выпуск не объявлен self-contained.
6. Создайте тестовую заметку. Если Windows защищает запуск неизвестной неподписанной программы, убедитесь, что файл скачан из официального релиза и совпадает SHA-256; не обходите предупреждения автоматически.

**Пока эти шаги нельзя рекомендовать широкой публике:** представленная сборка Windows содержит пять файлов (`exe`, `dll`, `deps.json`, `runtimeconfig.json`, `pdb`) и требует отдельно установленного .NET 8 Windows Desktop Runtime. Пакет не проверен на чистом компьютере.

## 3. Подключение синхронизации — после проверки Google OAuth

1. Откройте NorrNote21 на обеих платформах.
2. В Android выберите подключение Google Drive в настройках синхронизации и войдите в свой Google-аккаунт.
3. В Windows откройте настройки Google Drive. **В текущем коде Windows требуется вручную выбрать JSON-файл OAuth-клиента типа Desktop**, затем нажать подключение и войти через браузер. Это ещё один блокер простого публичного сценария: обычный пользователь не должен создавать Google Cloud проект ради установки приложения.
4. После завершения входа на обоих устройствах выполните синхронизацию и проверьте тестовую заметку.
5. Не удаляйте и не редактируйте вручную папку `NorrNote21` в Google Drive.

**Внимание:** простой вход для новых пользователей и выпуск общего OAuth-клиента пока не проверены. Поэтому синхронизация для каждого скачавшего сейчас не гарантирована.

## 4. Как проверить, что всё работает

- Создайте заметку на телефоне → синхронизируйте → проверьте её на компьютере.
- Прикрепите PDF на телефоне → проверьте на компьютере и откройте.
- Прикрепите документ на компьютере → проверьте на телефоне.
- Создайте напоминание и проверьте виджет/уведомление.
- Попробуйте «Поделиться»: заметка без вложений передаётся текстом; с вложениями — ZIP с `note.txt` и файлами.

## 5. Если возникла проблема

- **Windows просит .NET:** установите именно **Desktop Runtime**, не SDK.
- **Файл APK не устанавливается:** проверьте версию Android, подпись и не конфликтует ли уже установленная NorrNote11.
- **Нет Google Drive:** вход для сторонних пользователей ещё подготавливается; не публикуйте пароль или JSON с OAuth refresh token.
- **Нет заметки на втором устройстве:** убедитесь, что выбран один Google-аккаунт, запущена синхронизация и есть интернет.
- **Пропало вложение:** не удаляйте локальные базы, сначала сохраните копию облачной папки и обратитесь в поддержку.

Контакт: **support@norrvind.app**.
