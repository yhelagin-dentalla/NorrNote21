# Установка NorrNote21FE — Windows и Android

Friends Edition — бесплатная некоммерческая версия. Для синхронизации используйте один Google-аккаунт на телефоне и компьютере.

## Где скачать

Откройте [GitHub Releases](https://github.com/yhelagin-dentalla/NorrNote21FE/releases). В разделе **Assets** нужны Windows ZIP и Android APK версии 0.7.0. Не скачивайте `Source code (zip)` — это не программа. Перед распространением необходимо подтвердить, что Assets заменены окончательными проверенными сборками.

## Windows 10/11

1. Скачайте Windows ZIP, распакуйте целиком в постоянную папку, например `C:\Apps\NorrNote21FE`.
2. Запустите `NorrNote21FE.exe` из распакованной папки.
3. Отдельная установка .NET не требуется: пакет собран self-contained.
4. Создайте тестовую заметку, проверьте виджет.

Если Windows предупредит о неизвестном издателе, проверьте происхождение и SHA-256 файла. Это не означает, что Windows EXE подписан сертификатом Code Signing.

## Android 10+

1. Скачайте подписанный **release APK** Friends Edition.
2. Откройте APK на телефоне; если Android запросит разрешение на установку из выбранного браузера/файлового менеджера, разрешите его для этого источника.
3. Установите и откройте приложение. Идентификатор FE: `su.norrvind.norrnote.fe`; личную NorrNote21 устанавливать или удалять не нужно.
4. Создайте тестовую заметку и при необходимости добавьте виджет через меню виджетов Android.

## Подключение Google Drive

1. Войдите в один Google-аккаунт в обеих программах.
2. В настройках подключите Google Drive и предоставьте доступ, запрошенный приложением.
3. Дождитесь синхронизации, проверьте передачу заметки и PDF/изображения в обоих направлениях.
4. Рабочая папка FE — `NorrNote21FE`, а не `NorrNote21`; не переименовывайте и не редактируйте содержимое папки вручную.

## Если что-то не работает

- Проверьте интернет, одинаковый Google-аккаунт, запуск синхронизации и завершение её без ошибок.
- Если пропало вложение: остановите повторные синхронизации, сохраните копии локальных и облачных данных, напишите в поддержку.
- Не отправляйте в поддержку пароли, refresh-токены, личную базу или ключ подписи.
- При установке обновления APK используйте пакет с тем же сертификатом; без необходимости не удаляйте установленную FE с локальными данными.
